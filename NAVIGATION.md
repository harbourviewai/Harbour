# Navigation Guide

## 🗂️ **Page Structure**

The Harbourview AI Strategy Dashboard is now organized as separate pages for better navigation and user experience.

### **Main Entry Point**
- **`index.html`** - Automatically redirects to `overview.html`

### **Core Pages**

#### 📊 **Overview** (`overview.html`)
- **Purpose**: Executive summary and high-level insights
- **Content**: Vision statement, client objectives, key insights, impact snapshot
- **Best for**: C-level executives, initial presentations

#### 👥 **Teams** (`teams.html`)
- **Purpose**: Team-specific analysis and pain points
- **Content**: Interactive team selector, pain points, opportunities, discovery data, AI chat
- **Best for**: Department heads, team leads, operational managers

#### 💡 **Opportunities** (`opportunities.html`)
- **Purpose**: Detailed AI implementation opportunities
- **Content**: Comprehensive table, impact vs effort analysis, detailed modals
- **Best for**: Project managers, implementation teams, decision makers

#### 🎮 **Simulator** (`simulator.html`)
- **Purpose**: Interactive scenario planning
- **Content**: Opportunity checklist, real-time calculations, team impact heatmap
- **Best for**: Strategic planning sessions, "what-if" analysis

#### 🗺️ **Roadmap** (`roadmap.html`)
- **Purpose**: Implementation timeline and strategic planning
- **Content**: Phase overview, Gantt chart, dependencies, executive summary
- **Best for**: Project planning, timeline discussions

#### ⚙️ **Admin** (`admin.html`)
- **Purpose**: System administration and customization
- **Content**: Access controls, branding, export options, feedback system
- **Best for**: System administrators, customization needs

## 🔗 **Navigation Features**

### **Header Navigation**
- Consistent across all pages
- Active page highlighting
- Smooth hover effects
- Responsive design

### **Cross-Page Functionality**
- Modal system works across all pages
- JavaScript functionality maintained
- Consistent styling and behavior

## 🚀 **Usage Recommendations**

### **For Client Presentations**
1. Start with **Overview** for executive summary
2. Use **Teams** to show specific department impacts
3. Demonstrate **Simulator** for interactive planning
4. Show **Roadmap** for implementation timeline

### **For Internal Planning**
1. Use **Opportunities** for detailed analysis
2. Leverage **Simulator** for scenario testing
3. Reference **Roadmap** for project planning
4. Use **Admin** for customization

### **For Different Audiences**
- **Executives**: Overview → Simulator → Roadmap
- **Managers**: Teams → Opportunities → Simulator
- **Technical Teams**: Opportunities → Simulator → Admin
- **Project Teams**: Roadmap → Simulator → Opportunities

## 📱 **Mobile Navigation**

- Responsive header navigation
- Touch-friendly interface
- Optimized for tablet and mobile viewing
- Consistent experience across devices

## 🔧 **Technical Notes**

- Each page is self-contained but shares common assets
- JavaScript automatically detects current page for navigation highlighting
- All interactive features work independently on each page
- No server-side dependencies required
